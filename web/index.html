              1. Create a Google Cloud project — name it JARVIS, press Create. (Sign in with the Google account whose Gmail and Calendar JARVIS should use.)
              2. Enable the Google Calendar API and the Gmail API — press Enable on each (make sure the JARVIS project is selected at the top).
              3. Open Google Auth Platform → Get started: app name JARVIS, your email, audience External, finish.
              4. In Audience → Test users → Add users → add your own Gmail address and any other account you'll connect (e.g. your work email) → Save.
              5. In Clients → Create client: type Desktop app, name JARVIS, Create → Download JSON.
